Agent Ant — mobile mockups v2

Synthetic data only. Cleaner than v1: one idea per screen, fewer boxes, bigger type. Five-slot tab bar (Today · Jobs · + · Team · More). The team's names are placeholders for the trader's chat only: Penny the Receptionist, Ruth the Bookkeeper, Ed the Estimator (joins later).

Design rule: three taps or fewer. + is a shortcut: every option on it also lives on a tab (New job on Jobs, Add receipt on a job, Message on Team). Log a receipt: + → Snap → Confirm (3). Add a note to a job: + → Note → Save (3). Approve a lead: Today → card → Approve (3). Job spend against quote: Today → job (2). Ask the team: Team → person → type (3). A customer's messages: Jobs → job → messages (3).
